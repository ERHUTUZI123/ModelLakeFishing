usage: prepare_a0_graph.py [-h] --source SOURCE --out OUT [--verify-only]

Prepare the A0 graph from verified frozen bytes without rebuilding
features/edges. python -m scale1m.prepare_a0_graph --source <hgraph_rf> --out
<a0/graph> The CLI pins the source graph from A0.1. Existing outputs are never
overwritten.

options:
  -h, --help       show this help message and exit
  --source SOURCE
  --out OUT
  --verify-only    Read-only verification of an existing A0 graph
